## v2.1.0（当前版本）

- 新增 Chrome/Edge MV3 扩展 + Native Messaging 可选桥接；捕获时保存窗口内标签页 URL，恢复时按窗口一次性带 URL 打开。
- 设置新增「浏览器标签页」页，一键注册当前用户 Chrome/Edge native host，无需管理员权限。
- 扩展只读普通窗口的标题/URL，不联网、不读 Cookie/密码/历史/页面内容；无痕窗口不同步。
- 新增布局 JSON 往返、标签页标题解析、URL 过滤和按窗口启动测试；Rust 单测 90 项通过、1 项忽略。

## v2.0.4

- 浏览器窗口标题含“和另外 N 个页面”时识别为多标签窗口；浏览器已运行则不再补启新窗口，未运行则最多启动一个，避免标签页被拆成多个窗口。
- 显式“总是新开窗口”策略仍保留。
- 新增 2 个回归测试，Rust 单测 86 项通过、1 项忽略。

## v2.0.3

- 单次恢复启动上限 8 → 20，修复 11 个应用中后 3 个从未启动、被误记为“未找到”的问题。
- 唯一 exe 路径兜底：窗口类名/标题变化时仍能匹配；多候选仍走评分/歧义逻辑。
- 恢复途中消失的窗口显示“窗口已关闭或无法读取位置”，不再输出 `2147483647px`。
- WorkScene 自身窗口不再进入候选池。

## v2.0.2

- 新增本地诊断日志：记录窗口过滤原因、恢复匹配候选/分数/说明、启动与超时、自动快照跳过原因和 panic。
- 设置 → 关于、恢复报告页新增「导出诊断包」，包含日志、桌面扫描、设置和最近 20 次恢复记录，不包含数据库与快照。
- 日志按天滚动并保留 7 天；路径随数据目录。

## v2.0.0

- **数据可信度**：导入只默认启用常规安装目录下的程序；更新工作空间不再删除未打开应用；布局保存改为事务；多屏 profile 与画布同步。
- **恢复口径**：重试合并回完整报告并创建保护快照；崩溃恢复优先非 protection 快照；全部跳过/0 步不再记为成功。
- **存储与迁移**：快照富化原子写；设置事务提交；新增 `launch_priority` 迁移（`0003_launch_priority.sql`）。
- **系统集成**：休眠唤醒后暂停自动快照 90 秒；恢复中跳过自动快照；收工/退出与恢复互斥；工作空间快捷槽默认关闭且冲突可见。
- **前端一致性**：未保存布局不再被后台刷新覆盖；应用项局部更新；恢复/历史/设置/捕获/总览的错误态与状态清理补齐。

## v1.1.3

- 修正布局画布撤销 / 重做、设置页保存、捕获页重扫在 React StrictMode 下的重复副作用。
- 嵌套弹窗按 LIFO 响应 `Esc`；`ToastHost` 改为独立 Portal，不再被遮罩遮挡；`Ctrl+K` / `Ctrl+S` / `Ctrl+Z` / 方向键不再穿透模态框。
- 恢复报告页支持 `Ctrl+K` 切换空间；历史页与资源卡片切换空间自动重置；图标缓存大小写不敏感；窄屏折叠侧栏不再覆盖用户偏好。
- 工程侧修复「开机启动状态」测试的环境假设问题，发布流水线改为 tag 驱动。

## 数据兼容与升级

- 快照 JSON 带 `schemaVersion`，`load_scene` 会拒绝来自更高版本的快照并提示升级。
- 数据库迁移只追加，不修改历史迁移；v2.0.0 新增 `0003_launch_priority.sql`，旧的 `sort_order` 会回填为启动优先级。
- v2.0.0 起新建/未显式保存过设置的环境默认关闭 `Ctrl+Alt+1~9` 快捷槽；此前显式开启的用户保持开启。
- 卸载不会删除 `%LOCALAPPDATA%\WorkScene`，用户数据保留。
- 便携版数据位于解压目录的 `data\`，升级时替换程序文件、保留 `data\` 即可。

## 已知限制

1. **不支持 UWP / 应用商店应用**：捕获时识别并排除，不纳入恢复。
2. **双屏 / 混合 DPI 未实机验证**：显示器匹配、比例换算与 DPI 上下文已实现，但只有单屏实测数据。
3. **开机启动受环境限制**：注册表与启动文件夹都可能被安全软件或组策略拦截，界面会如实报错。
4. **安装包未签名**：首次运行会触发一次 SmartScreen 提示。
5. **暂无自动更新**。
6. 恢复记录最多展示最近 10 次；快照按工作空间计算保留数量。
7. 最小化窗口会恢复为普通窗口，报告中以 `stateRestored=false` 说明。
8. 全局主热键只支持 4 个预设组合，不支持任意按键录入；`Ctrl+Alt+1~9` 工作空间快捷槽默认关闭，需在设置中开启。
