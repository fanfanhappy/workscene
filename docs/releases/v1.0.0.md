# WorkScene v1.0.0

> 发布日期：2026-11-22 · Windows 10 / 11 (x64)

> **历史版本归档**：本页仅保留变更说明，未附带安装包。请下载 [最新版](https://github.com/fanfanhappy/workscene/releases/latest)。

第一个 1.0 版本。相比 0.1，重点是把「能跑」变成「稳定可用」：重写恢复引擎的匹配与坐标换算，补齐布局编辑器、全局热键、捕获页与整条前端交互链路。

## 本次更新

- **恢复引擎**：重做窗口匹配（进程名 / 路径 / 标题多信号加权）、多显示器坐标换算与失败重试，恢复报告逐项给出依据与偏差。
- **布局编辑器**：新增画布拖拽、缩放、磁性吸附、5 种一键分屏模板与撤销 / 重做，支持按显示器保存布局。
- **捕获与工作空间**：捕获页可展开查看被排除窗口及原因；工作空间支持收藏、色标、复制与 JSON 导入导出。
- **全局热键与托盘**：`Ctrl+Alt+W` 唤起、`Ctrl+Alt+1~9` 快捷槽、托盘恢复与一键快照。
- **回收站式安全**：覆盖与恢复前自动生成保护快照，异常退出后提示恢复。

## 已知限制

- 未在真实双屏 / 混合 DPI 环境验证。
- 不支持 UWP / 应用商店应用；管理员权限窗口受 UIPI 限制。
- 安装包未签名，暂无自动更新。
