# WorkScene v1.1.1

> 发布日期：2026-11-22 · Windows 10 / 11 (x64)

> **历史版本归档**：本页仅保留变更说明，未附带安装包。请下载 [最新版](https://github.com/fanfanhappy/workscene/releases/latest)。

集中修 bug 的补丁版本：更新检查、手动匹配、延迟启动，以及多屏坐标与安全校验。

## 修复

- **检查更新**：CSP 的 `connect-src` 未放行 `https://api.github.com`，导致「设置 → 关于 → 检查新版本」始终失败；现已放行并保留其余收紧策略。
- **手动添加软件**：手动选择的 `.exe` 在恢复时按进程名 / 路径匹配不上的问题，匹配器改为忽略大小写与扩展名差异。
- **启动延迟**：设置读写中 `delayMs` 字段名不一致，导致「延迟启动」不生效。
- **IDE 上下文参数**：修正项目目录在含空格路径下的参数拼接，避免打开成错误目录。
- **布局编辑器**：修正 Dialog 编辑窗口坐标时的输入与校验。
- **多屏 / DWM 坐标**：修正贴边、最大化窗口在任务栏工作区换算中的偏差。
- **安全校验**：加强外部导入与自定义启动参数的检查，危险条目默认不启用。

**完整变更**：[v1.1.0...v1.1.1](https://github.com/fanfanhappy/workscene/compare/v1.1.0...v1.1.1)
