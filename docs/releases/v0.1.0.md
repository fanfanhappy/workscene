# WorkScene v0.1.0

> 发布日期：2026-11-22 · Windows 10 / 11 (x64)

> **历史版本归档**：本页仅保留变更说明，未附带安装包。请下载 [最新版](https://github.com/fanfanhappy/workscene/releases/latest)。

第一个公开版本，验证了「捕获桌面 → 保存工作空间 → 一键恢复」这条主线。

## 包含

- 基于 Win32 API 的窗口捕获，过滤系统窗口、工具窗口与其他虚拟桌面的隐藏窗口。
- 工作空间：应用清单 + 窗口比例布局 + 文件 / 文件夹 / 网址资源，支持导入导出 JSON。
- 一键恢复：拉起缺失程序、按比例摆放窗口、失败项给出原因。
- 快照：手动快照、自动快照与恢复前保护快照，支持时间线与预览。
- 全局热键、系统托盘、开机启动、深浅色主题与首次使用引导。
- 安装版（NSIS）与绿色便携版两种形态。

## 已知限制

- 本版本未在真实多屏环境验证，双屏 / 混合 DPI 相关能力属于「已实现、未实测」。
- 不支持 UWP 应用；管理员权限窗口受 UIPI 限制。
- 安装包未签名，暂无自动更新。
