# WorkScene v1.1.0

> 发布日期：2026-11-22 · Windows 10 / 11 (x64)

> **历史版本归档**：本页仅保留变更说明，未附带安装包。请下载 [最新版](https://github.com/fanfanhappy/workscene/releases/latest)。

一次功能量较大的升级：真正的 L2 上下文捕获、像素级贴边、多屏拓扑方案、生命周期钩子，以及零轮询的全局热键线程。

## 亮点

- **L2 上下文自动捕获**：扫描桌面时识别已打开的资源管理器目录，以及 VS Code / Cursor / Windsurf / Trae / Antigravity 当前打开的项目，勾选即可保存为资源。
- **0px 贴边分屏**：使用 `DWMWA_EXTENDED_FRAME_BOUNDS` 补偿 Windows 透明阴影边框，消除 Win10/11 左右分屏与贴边的 7~14px 缝隙。
- **多屏拓扑方案（Display Profiles）**：同一工作空间可为「单屏 / 双屏 / 扩展屏」分别保存窗口排布，恢复时按当前显示器组合自动匹配。
- **生命周期钩子**：可为工作空间配置「恢复前 / 收工后」本地命令（默认关闭），联动开发服务或环境切换脚本。
- **零轮询热键线程**：全局快捷键改为阻塞式 `GetMessageW` + `PostThreadMessageW`，空闲时零 CPU 唤醒，响应 < 1ms。
- **后台状态反馈**：托盘恢复异常或繁忙时通知前端并更新托盘提示。

## 交互与画布

- `MonitorCanvas` 缩略图直接显示软件名与最大化 / 最小化标识。
- 编辑工作空间信息时可直接绑定 `Ctrl+Alt+1~9` 快捷槽。
- 资源列表支持内联编辑与删除确认。
- 「设置 → 关于」新增手动检查 GitHub 新版本。
