# WorkScene v2.1.0

> 发布日期：2026-11-23 · Windows 10 / 11 (x64)

新增可选的**浏览器标签页 URL 恢复**：通过 Chrome/Edge 扩展 + Native Messaging，把当前窗口里的标签页 URL 保存到工作空间，恢复时按窗口一次性打开，不再把标签页拆成多个窗口。

## 新增

### 浏览器扩展桥

- 轻量 Chrome / Edge MV3 扩展，只申请 `tabs`、`nativeMessaging`、`storage` 权限。
- 扩展监听标签页打开/切换/关闭/窗口焦点变化，把当前窗口、标签顺序和 URL 写入本机。
- 扩展不访问网络，不读取 Cookie、密码、历史记录或页面内容。
- Native Messaging host 复用 `WorkScene.exe`：Chrome/Edge 启动时通过父进程识别进入 host 模式，不打开 GUI。
- 首次使用：设置 → 浏览器标签页 → **安装本机连接** → **打开扩展目录** → 在 `chrome://extensions` / `edge://extensions` 加载已解压扩展。

### 捕获与恢复

- 捕获时按窗口标题把扩展标签页匹配到真实 HWND，保存 `title/url/active`。
- 恢复时按窗口一次性传 URL：
  `msedge.exe --new-window url1 url2 url3`
  多个标签页留在同一个窗口，不再拆成独立窗口。
- 浏览器已经打开时优先复用现有窗口，保留原标签页；只有浏览器关闭或确实缺窗口时才启动。
- 只保存 `http(s)://` 与 `file://` 页面；单个窗口限制 URL 数量与命令行长度。

### 设置页

- 新增「浏览器标签页」页：显示 Chrome/Edge 注册状态、最近同步时间和标签页数量。
- 一键写入当前用户的 Chrome/Edge Native Messaging 注册表项，无需管理员权限。
- 扩展 ID 固定为 `pijcngaddijnocfoikelinkigoacigbl`。

## 限制

- 扩展需要手动加载（Chrome/Edge 不允许应用静默安装扩展）；安装一次即可。
- 浏览器完全关闭时 WorkScene 没有标签页数据，只能打开空白窗口；恢复前保持浏览器打开可保留标签页。
- 无痕窗口不同步；只同步普通窗口。
- 多 Chrome/Edge 配置文件的同步以最后写入的快照为准。

## 验证

- `cargo test --lib`：90 项通过、1 项手工诊断用例默认忽略。
- 新增标签页标题解析、URL 过滤、布局 JSON 往返、按窗口带 URL 启动等测试。
- `tsc --noEmit`、`vite build` 通过。

## 安装

| 形态 | 文件名 | 说明 |
|---|---|---|
| 标准安装版（推荐） | `WorkScene_2.1.0_x64-setup.exe` | 当前用户安装，无需管理员权限 |
| 绿色便携版 | `WorkScene-2.1.0-portable.zip` | 解压后双击 `start.cmd`；需要系统已有 WebView2 Runtime |

- 校验下载：对照 `SHA256SUMS.txt`，或执行 `certutil -hashfile <文件名> SHA256`。
- 未做代码签名，首次运行如遇 SmartScreen，请点「更多信息 → 仍要运行」。

## 升级说明

- 没有数据库迁移；已有工作空间、快照、设置保留。
- 旧工作空间没有标签页数据，重新捕获一次即可开始保存 URL。
- 便携版扩展目录随 ZIP 一起提供；安装版在安装目录 `resources/browser-extension`。
