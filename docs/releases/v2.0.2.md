# WorkScene v2.0.2

> 发布日期：2026-11-23 · Windows 10 / 11 (x64)

一次以**可诊断性**为核心的补丁版本：当窗口被跳过、应用没有启动或恢复结果与预期不符时，不再只能靠猜，而是能看到每个窗口的过滤原因、匹配候选、启动结果和最终偏差。

## 本次更新

### 本地诊断日志

- 新增本地日志系统，默认写入 `%LOCALAPPDATA%\WorkScene\logs\`（便携版写入 `data\logs\`）。
- 按天滚动，默认保留 7 天；可用环境变量 `WORKSCENE_LOG` 调整级别。
- 记录内容：
  - 每个窗口被捕获或被过滤的进程名、类名、标题和具体原因；
  - 恢复时每个目标的候选窗口数量、最优候选、匹配说明、目标/实际矩形和最终偏差；
  - 应用启动、可执行文件缺失、单次恢复启动上限、启动等待超时；
  - 自动快照被跳过/被丢弃的原因（恢复中、休眠唤醒、指纹未变化、间隔未到）；
  - 恢复摘要、错误码和未处理 panic。
- 日志只保存在本机，不上传；包含窗口标题和路径，导出前会提示。

### 一键诊断包

- 设置 → 关于新增 **「打开日志目录」** 和 **「导出诊断包」**。
- 恢复报告页在未完成/跳过时也可直接 **「导出诊断」**。
- 诊断包内容：日志、当前桌面窗口/显示器扫描、设置、最近 20 次恢复记录与步骤、应用版本；默认不包含数据库和快照 payload。

## 如何排查“应用被跳过”

1. 复现一次恢复；
2. 在恢复报告页点「导出诊断」；
3. 把生成的 `WorkScene-diagnostics-*.zip` 发回。

日志中搜索 `restore window skipped`、`window excluded from capture`、`launch skipped` 或 `restore launch total cap reached`，即可看到具体原因。

## 安装

| 形态 | 文件名 | 说明 |
|---|---|---|
| 标准安装版（推荐） | `WorkScene_2.0.2_x64-setup.exe` | 当前用户安装，无需管理员权限 |
| 绿色便携版 | `WorkScene-2.0.2-portable.zip` | 解压后双击 `start.cmd`；需要系统已有 WebView2 Runtime |

- 校验下载：对照 `SHA256SUMS.txt`，或执行 `certutil -hashfile <文件名> SHA256`。
- 未做代码签名，首次运行如遇 SmartScreen，请点「更多信息 → 仍要运行」。

## 升级说明

- 本版本没有数据库迁移，直接覆盖安装即可；工作空间、快照和设置保留。
- 日志目录会随数据目录创建；卸载不删除用户数据。

## 已知限制

- 日志会包含窗口标题和路径，请只发送给可信任的人。
- 未在真实双屏 / 混合 DPI 环境完成验证。
- 暂不支持 UWP / 应用商店应用；管理员权限窗口受 UIPI 限制。
