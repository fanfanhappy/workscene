# WorkScene v2.0.4

> 发布日期：2026-11-23 · Windows 10 / 11 (x64)

修复浏览器多标签页在恢复时被拆成多个独立窗口的问题。

## 问题

场景里保存的是一个浏览器窗口，窗口标题显示“某某页面 和另外 N 个页面”，说明里面是多个标签页。恢复时启动计划按“缺少几个窗口就补几个”执行，会把同一浏览器的多个窗口/标签页逐个启动，结果看起来像被拆成多个单独页面。

## 修复

- 识别浏览器窗口标题中的标签页信号（“和另外 N 个页面” / “and N more pages”）。
- 浏览器已经运行时：**不再为带标签页的场景窗口补启新窗口**，直接复用现有窗口；多出来的场景窗口在恢复报告里如实跳过。
- 浏览器未运行时：同一浏览器的多个带标签页窗口**最多只启动一个**，避免一次弹出多个空白窗口。
- 显式选择“总是新开窗口”的应用仍尊重用户选择。
- 本项目不读取浏览器标签页 URL；浏览器关闭时只能打开一个空白窗口，标签页内容本身无法重建。浏览器保持打开时，恢复不会破坏原有标签页。

## 验证

- 新增回归测试：
  - 浏览器已运行且窗口含标签页 → 不再生成额外启动计划；
  - 浏览器未运行且有 3 个带标签窗口 → 只启动 1 个。
- `cargo test --lib`：86 项通过、1 项手工诊断用例默认忽略。

## 安装

| 形态 | 文件名 | 说明 |
|---|---|---|
| 标准安装版（推荐） | `WorkScene_2.0.4_x64-setup.exe` | 当前用户安装，无需管理员权限 |
| 绿色便携版 | `WorkScene-2.0.4-portable.zip` | 解压后双击 `start.cmd`；需要系统已有 WebView2 Runtime |

- 校验下载：对照 `SHA256SUMS.txt`，或执行 `certutil -hashfile <文件名> SHA256`。
- 未做代码签名，首次运行如遇 SmartScreen，请点「更多信息 → 仍要运行」。

## 升级说明

- 本版本没有数据库迁移，直接覆盖安装即可。
- 建议先保持浏览器窗口打开，再执行恢复；这样标签页会原样保留。
- 如果仍出现拆分，请复现后导出诊断包，日志会记录 `browser has tabs ... skip additional window launch` 是否命中。
