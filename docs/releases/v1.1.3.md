# WorkScene v1.1.3

> 发布日期：2026-11-23 · Windows 10 / 11 (x64)

一次以**健壮性与交互一致性**为主的更新：修掉 React StrictMode 下的重复副作用，补齐弹窗 / 快捷键 / Toast 的层级规则，并让页面切换后的状态不再互相污染。

## 本次更新

### 前端健壮性

- **StrictMode 零副作用**：修正布局画布撤销 / 重做、设置页保存、捕获页重扫中的非纯 state updater，开发模式下不再重复执行。
- **弹窗层级与快捷键栈**：嵌套弹窗按 LIFO 顺序响应 `Esc`（先关最上层确认框）；`ToastHost` 改为独立 Portal（`z-[70]`），不再被弹窗遮罩盖住；`Ctrl+K` / `Ctrl+S` / `Ctrl+Z` / 方向键不再穿透模态框。
- **页面切换与缓存一致性**：恢复报告页可用 `Ctrl+K` 切换到另一个空间；历史页与资源卡片切换空间时自动重置状态；Windows 应用图标缓存改为大小写不敏感匹配；窄屏自动折叠侧栏不再永久覆盖用户偏好。

### 工程

- 修复「开机启动状态」单元测试对环境做了错误假设的问题：注册表可写的机器上测试会误报失败，导致发布流水线从未跑通。现在按真实结果分支断言，并在测试结束后清理启动项。
- 发布流水线改为 **tag 驱动**：`v*` tag 触发构建、测试、NSIS 打包、便携版压缩与 Release 发布，发布说明按版本读取 `docs/releases/<tag>.md`。

## 安装

| 形态 | 文件名 | 说明 |
|---|---|---|
| 标准安装版（推荐） | `WorkScene_1.1.3_x64-setup.exe` | 当前用户安装，无需管理员权限；数据在 `%LOCALAPPDATA%\WorkScene` |
| 绿色便携版 | `WorkScene-1.1.3-portable.zip` | 解压后双击 `start.cmd`，数据保存在同目录 `data\` |

- 校验下载：对照随附的 `SHA256SUMS.txt`，或执行 `certutil -hashfile <文件名> SHA256`。
- 未做代码签名，首次运行如遇 SmartScreen，请点「更多信息 → 仍要运行」。

## 已知限制

- 未在真实双屏 / 混合 DPI 环境完成验证（单屏 3840×2160 @150% 已验证）。
- 暂不支持 UWP / 应用商店应用；管理员权限窗口受 UIPI 限制。
- 暂无自动更新。
