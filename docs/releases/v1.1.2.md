# WorkScene v1.1.2

> 发布日期：2026-11-22 · Windows 10 / 11 (x64)

> **历史版本归档**：本页仅保留变更说明，未附带安装包。请下载 [最新版](https://github.com/fanfanhappy/workscene/releases/latest)。

把「便携」和「完整性」两件事做扎实：绿色版真正把数据留在同目录，复制 / 导出 / 备份 / 快照都不再丢配置。

## 本次更新

- **便携版真正绿色**：`start.cmd` 启动时设置 `WORKSCENE_DATA_DIR=%~dp0data`，数据库、快照与 WebView 缓存都留在压缩包解压目录，拷走文件夹即可迁移。
- **全生命周期配置保留**：复制、导出、全量备份与历史快照都会完整保留工作空间的资源列表、启动参数 / 优先级 / 延迟、色标、多屏拓扑方案与生命周期钩子；外部导入的钩子默认停用。
- **视图与安全细节**：工作空间列表与紧凑视图同步显示 `Ctrl+Alt+N` 快捷槽徽章；全量备份导入增加二次确认；外部导入立即弹出风险提醒。

## 已知限制：未在真实双屏 / 混合 DPI 环境验证；不支持 UWP 应用；管理员权限窗口受 UIPI 限制；暂无自动更新。
