# WorkScene v2.0.0

> 发布日期：2026-11-23 · Windows 10 / 11 (x64)

WorkScene 的首个 **2.0 大版本**。这次不追求新按钮，而是把捕获、恢复、快照、导入、设置和快捷键的“边界条件”整体收紧：**少丢配置、少误操作、失败可解释、升级可回退**。

## 本次更新

### 数据与恢复可信度

- **导入工作空间安全边界**：只有常规安装目录下的可执行文件才默认启用；下载、桌面、临时目录、UNC 与非常规路径的应用默认停用。导入预检会列出文件将登记的全部可执行文件，全量备份导入增加 20 MB 上限。
- **“更新已有工作空间”不再删除未打开的应用**：只替换本次捕获到的应用与窗口，未捕获应用及其上次布局、启动参数、优先级、延迟全部保留。
- **布局保存原子化**：删除窗口与更新坐标合并为一次事务，失败不会留下“删了一半、摆了一半”的布局。
- **多屏方案同步**：保存画布或重新捕获后，当前显示器组合的专属布局会同步更新，不再被旧 profile 覆盖；显示器签名加入相对位置与 DPI。
- **启动优先级独立**：新增 `launch_priority` 数据库列，取消“优先启动”不会再改变应用在列表中的位置。数据库迁移会在升级启动时自动执行。
- **重试报告合并**：重试结果不再覆盖完整恢复报告；重试前会创建保护快照，0 步重试不会显示成功，同名目标已有成功项时不再做单条重试。
- **崩溃恢复选对快照**：优先使用非“恢复前保护”的现场快照，并在横幅标明快照时间与类型。
- **快照与设置写入更稳**：快照富化改为原子写；设置整批事务提交；删除快照文件失败会如实报错，不留下无法清理的孤儿文件。
- **恢复状态口径**：全部跳过 / 0 步恢复不再记为 `completed`，历史页与总览显示“跳过”而不是“成功”。

### 稳定性与系统集成

- **休眠/唤醒保护**：墙钟一次跳变超过 2 分钟判定为休眠唤醒，暂停自动快照 90 秒，避免驱动重排后的窗口坐标被写成现场；恢复过程中自动快照直接跳过。
- **恢复互斥扩大**：一键收工、托盘收工也会获取恢复锁；恢复中托盘“退出”会提示等待，而不是打断半恢复的桌面。
- **热键默认更克制**：`Ctrl+Alt+1~9` 工作空间快捷槽默认关闭，新用户只注册 `Ctrl+Alt+W`；设置页可随时开启。
- **热键冲突可见**：启动时真实注册结果会记录并暴露给设置页，主热键或快捷槽被占用时直接显示原因；新组合注册失败会保留原热键。
- **导入/快照/设置失败不再伪装成空数据**：工作空间、快照、恢复记录、存储、健康检查的读取错误都会显示错误与重试入口。

### 前端交互

- 布局草稿按窗口 id 合并，修改备注、开关应用、增删资源不再静默清空未保存的拖拽结果。
- 应用项改为局部更新，失焦保存启动参数与点击开关不会互相覆盖。
- 恢复报告重试合并、撤销结果分支、外部恢复任务提示与取消入口、历史 diff 时间方向、清理后的选中状态均已修正。
- 弹窗增加初始焦点、Tab 焦点陷阱与焦点恢复；路由切换会重置错误边界；`Ctrl+K` 长按不再反复开关面板。

## 升级说明

- **数据库**：启动时自动执行 `0003_launch_priority.sql`，旧数据的 `sort_order` 会回填为启动优先级，不会丢失应用或窗口。
- **快捷槽**：新安装默认关闭 `Ctrl+Alt+1~9`；此前显式保存过开启设置的用户保持开启，可随时在「设置 → 外观与热键」调整。
- **导入**：外部 JSON 中非常规安装路径的应用会默认停用，确认来源可信后可手动启用。
- **快照**：旧快照仍按原 `schemaVersion` 读取；更高版本创建的快照会提示升级后再打开。

## 安装

| 形态 | 文件名 | 说明 |
|---|---|---|
| 标准安装版（推荐） | `WorkScene_2.0.0_x64-setup.exe` | 当前用户安装，无需管理员权限；数据在 `%LOCALAPPDATA%\WorkScene` |
| 绿色便携版 | `WorkScene-2.0.0-portable.zip` | 解压后双击 `start.cmd`，数据保存在同目录 `data\`；需系统已有 WebView2 Runtime |

- 校验下载：对照随附的 `SHA256SUMS.txt`，或执行 `certutil -hashfile <文件名> SHA256`。
- 未做代码签名，首次运行如遇 SmartScreen，请点「更多信息 → 仍要运行」。

## 已知限制

- 未在真实双屏 / 混合 DPI 环境完成验证（单屏 3840×2160 @150% 已验证）。
- 暂不支持 UWP / 应用商店应用；管理员权限窗口受 UIPI 限制。
- 反作弊游戏、自绘窗口、输入法悬浮窗等不保证可恢复。
- 全局主热键只支持 4 个预设组合，不支持任意按键录入；工作空间快捷槽默认关闭。
- 暂无自动更新。
