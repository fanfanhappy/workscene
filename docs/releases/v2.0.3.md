# WorkScene v2.0.3

> 发布日期：2026-11-23 · Windows 10 / 11 (x64)

根据 v2.0.2 诊断包定位并修复了“很多应用被跳过”的主要问题。

## 诊断结论

一份真实工作空间的恢复日志显示：

- 场景有 **16 个窗口 / 11 个待启动应用**，恢复计划也生成了 11 项；
- 但单次恢复总启动上限只有 **8**，启动 8 个后直接停止；
- 后面的 PowerPoint 等应用因此从未启动，再拿它们和无关窗口匹配，得分只有 `0.05`，被记为“未找到”；
- 应用升级后窗口类名变化（例如向日葵的 `FLUTTER_RUNNER_WIN32_WINDOW` 与旧快照的 `FlutterMultiWindow` 不同），路径相同也会被 `0.70` 阈值拒绝；
- 个别窗口在恢复途中关闭，报告出现 `2147483647px` 的异常偏差；
- WorkScene 自己的窗口被当作候选窗口参与打分，产生无意义的低分候选。

## 修复

### 启动上限

- 单次恢复总启动上限从 **8 提升到 20**，覆盖常见多应用工作空间；超过上限仍会记录明确日志。
- 保留每应用 3 个实例的上限，避免异常工作空间无限拉起。

### 匹配

- 新增**唯一 exe 路径兜底**：目标路径在当前桌面只有一个候选时，即使窗口类名/标题变化也允许匹配，并在报告里标注“按进程路径唯一匹配”。
- 同 exe 有多个候选时仍走原有评分/歧义逻辑，不会乱挑。
- WorkScene 自身窗口不再进入候选池（M1 模拟窗口仍保留，供自检）。

### 报告

- 窗口在恢复过程中关闭/无法读取位置时，显示“窗口已关闭或无法读取位置，未能恢复”，错误码 `window_control_denied`，不再出现 `2147483647px`。
- 日志继续记录候选分数、路径、类名和跳过原因。

## 安装

| 形态 | 文件名 | 说明 |
|---|---|---|
| 标准安装版（推荐） | `WorkScene_2.0.3_x64-setup.exe` | 当前用户安装，无需管理员权限 |
| 绿色便携版 | `WorkScene-2.0.3-portable.zip` | 解压后双击 `start.cmd`；需要系统已有 WebView2 Runtime |

- 校验下载：对照 `SHA256SUMS.txt`，或执行 `certutil -hashfile <文件名> SHA256`。
- 未做代码签名，首次运行如遇 SmartScreen，请点「更多信息 → 仍要运行」。

## 升级说明

- 本版本没有数据库迁移，直接覆盖安装即可；工作空间、快照和设置保留。
- 建议升级后重新执行一次恢复；仍被跳过的项目，用恢复报告页的「导出诊断」发回日志。

## 已知限制

- 部分应用（如向日葵的独立远程会话窗口）无法从主窗口重建缺失的会话窗口；这类跳过是真实限制。
- 未在真实双屏 / 混合 DPI 环境完成验证。
- 暂不支持 UWP / 应用商店应用；管理员权限窗口受 UIPI 限制。
